# FOCUS Android

Android-ready package for FOCUS V7.

- Offline-first
- No login/backend
- No notifications
- No special permissions
- Local app data is stored on the device via WebView DOM storage

## Build
Open as an Android Gradle project and run `gradle assembleDebug`, or use the included GitHub Actions workflow.

APK output: `app/build/outputs/apk/debug/app-debug.apk`
